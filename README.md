# PHAX Stockfish Chess AI ♟️

> Интерактивный шахматный ИИ-движок в браузере на базе Stockfish NNUE (3500+ ELO) и Chess.js.

![Chess Engine](https://img.shields.io/badge/Engine-Stockfish_3500+_ELO-amber?style=for-the-badge)
![Status](https://img.shields.io/badge/Demo-Live_on_GitHub_Pages-emerald?style=for-the-badge)

## ⚡ Особенности

- **Гроссмейстерский уровень (Stockfish Web Worker):** Расчет ходов на глубину 15+ полуходов, оценка позиции в реальном времени.
- **Интерактивная доска:** Подсветка легальных ходов, шаха, последнего хода и звуковые эффекты через Web Audio API.
- **Дерзкие комментарии:** Бот реагирует на ходы соперника, комментирует зевки и тактические ошибки.
- **3 уровня сложности:** Непобедимый (3500+ ELO), Мастер (2200 ELO), Любитель (1400 ELO).
